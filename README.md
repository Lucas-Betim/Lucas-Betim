### 📊 Análise de Churn de Clientes

Análise exploratória de aproximadamente **50 mil registros**, buscando
identificar os principais fatores associados ao cancelamento de clientes.

`Python` `Pandas` `Plotly` `Data Analysis`

Foram identificados padrões relacionados a:

- Tipo de contrato
- Frequência de utilização
- Contatos com suporte
- Atrasos de pagamento

O objetivo foi transformar os dados em **insights aplicáveis a estratégias de retenção**.

➡️ **[Ver projeto](LINK_DO_REPOSITORIO)**
